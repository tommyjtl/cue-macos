# Cue sound effects

Drop bundled sound files here. Xcode picks them up automatically.

| File name (any supported extension) | Plays when |
| --- | --- |
| `collect` or `context-attached` | A screenshot, selected text, or browser page is attached to the context stack |
| `chat` or `chat-opened` | The chat composer overlay is shown |

Supported extensions: `.caf`, `.aiff`, `.wav`, `.mp3` (`.caf` or `.aiff` recommended).

Example:

- `collect.mp3`
- `chat.mp3`

Sound effects require macOS **Play user interface sound effects** (System Settings → Sound) and Cue **General → Play sound effects**.
